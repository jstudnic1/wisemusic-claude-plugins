# Wisemusic OS: Claude marketplace

Generated by `companyos-kit plugin` from `skills/` and `instances/wisemusic/skills/`. Do not edit it here:
change the skills in the Company OS repository, regenerate, and push.

One plugin, `wisemusic-os` (Wisemusic OS), has two parts:

* the company connector `wisemusic-os` at https://mcp.wisemusic.vono.studio/mcp, with no secrets: each person signs in with their own account;
* 25 skills.

## Roll it out (an Owner of the Claude organisation)

1. Push this folder to a **private** GitHub repository (or GitLab) and give the Claude GitHub App access to
   that repository only.
2. In claude.ai, go to **Organization settings > Plugins & skills > Add > Sync from GitHub**. Choose the
   repository, leave **Sync automatically** on, and set the default access to **Installed by default**, or
   **Required** so nobody can remove it.
3. Check it as a member: **Customize > Plugins** shows Wisemusic OS. Connect `wisemusic-os` on its **Connectors**
   tab and ask Claude which skills it has.

Every push to the default branch is a release; there is no version to raise. People who use Claude Code
signed in with their claude.ai account get the plugin there too (Claude Code 2.1.273 or later).

## Claude Code without a claude.ai sign-in (optional)

One person installs it with `/plugin install wisemusic-os --marketplace OWNER/REPOSITORY` (Claude Code 2.1.275
or later). For every machine, add this to managed settings (**Organization settings > Claude Code >
Managed settings**). Each machine then needs read access to the repository.

```json
{
  "extraKnownMarketplaces": {
    "wisemusic": { "source": { "source": "github", "repo": "OWNER/REPOSITORY" }, "autoUpdate": true }
  },
  "enabledPlugins": { "wisemusic-os@wisemusic": true }
}
```
